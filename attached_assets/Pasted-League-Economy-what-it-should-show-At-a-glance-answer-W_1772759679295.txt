Who controls future picks?

Who has the most tradable surplus?

1) Economy Overview (the hero view)
A) “Power vs Future” Quadrant (2x2)

Plot each team on a quadrant:

X-axis = Now Score (Redraft rank / starter value)

Y-axis = Future Score (Draft rank + Dynasty roster quality)

Quadrants:

Dynasty Death Star (high now, high future)

Rebuild With Ammo (low now, high future)

This is the single best “economy chart.”

No need for fancy charts initially — a quadrant grid with team chips is enough.

B) “League Parity” Score (shareable)

Compute how balanced the league is:

Parity Score (0–100) using dispersion of Power scores.

Simple method:

Calculate std dev of powerScore across teams

Normalize to 0–100 scale (lower spread = higher parity)

Output:

Parity: 78/100 (High)

Description: “Most teams are within 8 points of the median.”

The “League Economy” metrics (exact formulas)
A) Now Score

Use:

Redraft rank OR starter value

normalized to 0–100

Example:

nowScore = percentile(starterValueAllTeams, thisTeamStarterValue) * 100
B) Future Score

Combine:

Dynasty roster strength (youth / long-term)

Draft capital value

Example:

futureScore = 0.6 * dynastyPercentile + 0.4 * draftPercentile
C) League Parity (0–100)

Simple:

parity = 100 - normalize(stdDev(powerScore), minStd, maxStd) * 100

(You can calibrate min/max based on typical ranges; start with a clamp.)

D) Picks Monopoly %
pickShare = teamPickValue / sumAllTeamsPickValue
E) Positional Scarcity Index

Quick version:

For each position, compute the ratio:

(sum of top 3 teams starter value) / (sum of bottom 3 teams starter value)

Then:

= 1.8 => High scarcity

1.3–1.79 => Medium

< 1.3 => Low

This page visualizes league-wide economic dynamics using our existing computed metrics:
- Power score
- Dynasty rank / dynasty value
- Redraft rank / starter value
- Draft capital value

Sections:

1) Economy Overview
A) Quadrant view (Power vs Future)
