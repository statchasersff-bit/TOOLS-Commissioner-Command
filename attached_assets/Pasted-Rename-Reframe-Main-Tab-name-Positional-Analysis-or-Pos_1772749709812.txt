How to calculate “surplus” and “need”

This is the key.

You already have value-source-driven player values (FantasyCalc). Use that.

Step 1: Determine starters baseline

Based on league settings:

starters needed at each position

use typical assumptions if unknown

Example:

QB: 1 (SF might value 2)

RB: 2

WR: 2

TE: 1

FLEX: count toward best remaining RB/WR/TE

Step 2: Compute each team’s “starter set” value per position

For each team:

sort players at position by value desc

take top N starters required

sum values → Starter Strength

Step 3: Compute depth score

Sum next M players (bench tier) → Depth Strength

Step 4: Convert to league percentile ranks

For each position:

rank teams by starter strength

label:

Top 25% = Surplus

Middle 50% = Neutral

Bottom 25% = Need

That’s easy to understand and consistent.

Bonus: “Surplus amount”

Surplus amount = (your starter+depth value) − (league median)

What to tell Replit AI (copy/paste)
Replace the existing “Trade Finder” section with a new main tab called “Positional Analysis” (or “Position Market”).

Goal:
Analyze positional surplus/need across the league and generate trade opportunities based on supply/demand.

Sub-tabs:
1) Position Overview
2) Surplus & Needs
3) Trade Opportunities
4) Targets

Calculations (value-source driven):
- Use the selected Value Source values (FantasyCalc) for all player values.
- Determine starters baseline from league settings (or default assumptions: QB1, RB2, WR2, TE1, FLEX2).
- For each team and position:
  - StarterStrength = sum(top N players at that position by value)
  - DepthStrength = sum(next M players by value) (M=3 default)
  - TotalPosStrength = StarterStrength + 0.5*DepthStrength
- For each position, rank teams by TotalPosStrength and label:
  - Top 25%: Surplus
  - Middle 50%: Neutral
  - Bottom 25%: Need
- Compute “Surplus Amount” = team TotalPosStrength - league median for that position.

UI:
Position Overview:
- Heatmap/matrix: Teams x Positions with colored status (Surplus/Neutral/Need) and rank in tooltip.

Surplus & Needs:
- Position selector chips (QB/RB/WR/TE).
- Two columns listing Surplus teams vs Need teams.
- Each team row shows:
  - position rank
  - surplus amount
  - quick action “Find Deals”.

Trade Opportunities:
- Generates partner rows for the user’s selected team:
  - Partner team
  - Why badges (e.g., “RB Need”, “WR Surplus”)
  - Suggested targets (players from their surplus position)
  - Suggested offers (assets from my surplus positions + picks)
- Each row has button “Build Trade” that opens Trade Calculator with assets prefilled.

Targets:
- For selected position, show:
  - “Buy Targets” (from surplus teams)
  - “Sell Candidates” (from my roster) if I have surplus
- Each player card includes value, age, team, and action buttons.

Premium UX:
- Use StatChasers navy/gold styling, rounded-2xl cards, gold underline headers.
- Add a side drawer on clicking a team to show deeper “Market Profile” and one-click trade builder.
- Mobile responsive: matrix scroll, lists stack, sticky headers.
