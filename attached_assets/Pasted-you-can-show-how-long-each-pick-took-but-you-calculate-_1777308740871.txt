🧠 What Sleeper API actually provides

When you fetch draft picks (/drafts/{draft_id}/picks), each pick object includes:

picked_at → timestamp (ms since epoch)
draft_slot
roster_id
player info

👉 There is NO built-in “time to pick” field
👉 There is NO explicit “timer duration used” field

⏱️ How you calculate pick time

You compute it like this:

pick_time = current_pick.picked_at - previous_pick.picked_at

So yes — when a user clicks into a live draft, you can absolutely show:

Time per pick
Running timers
Manager speed

⚠️ Important limitations

Be aware of these edge cases:

1. First pick
No previous timestamp → either:
skip it
or use draft.start_time (if available)
2. Pauses / draft delays
If commissioner pauses draft, time still accumulates
👉 Your data will show inflated pick times

(You can optionally cap or flag long picks like “>10 min”)

3. Auto picks
Sleeper does NOT reliably expose a clean auto-pick flag
You might see it in metadata, but it’s inconsistent

👉 Don’t rely on it heavily (your earlier approach = correct)
