Add authenticated Sleeper GraphQL support for the live draft queue feature.

Goal:
In the live draft room, Dynasty Command should be able to fetch and display the user’s Sleeper draft queue for the active draft.

Discovered Sleeper operation:
POST https://sleeper.com/graphql

operationName: draft_queue

Query:
query draft_queue($draft_id: ID!) {
  draft_queue(draft_id: $draft_id)
}

Important:
Sleeper’s browser request sends:
authorization: <JWT>
not:
authorization: Bearer <JWT>

Do not log, print, expose, or store the token insecurely.

Implementation requirements:

1. Use the existing Sleeper GraphQL client.

If there is no centralized client yet, create:

src/lib/sleeper/graphql/client.ts

with:

export async function sleeperGraphql(token: string, payload: any) {
  const res = await fetch("https://sleeper.com/graphql", {
    method: "POST",
    headers: {
      "content-type": "application/json",
      "authorization": token,
      "x-sleeper-graphql-op": payload.operationName,
    },
    body: JSON.stringify(payload),
  });

  if (!res.ok) {
    throw new Error(`Sleeper GraphQL error: ${res.status}`);
  }

  const json = await res.json();

  if (json.errors) {
    throw new Error(json.errors.map((e: any) => e.message).join(", "));
  }

  return json.data;
}

2. Add draft queue query file.

Create:

src/lib/sleeper/graphql/queries/draftQueue.ts

Add:

import { sleeperGraphql } from "../client";

export const DRAFT_QUEUE_QUERY = `
  query draft_queue($draft_id: ID!) {
    draft_queue(draft_id: $draft_id)
  }
`;

export async function getDraftQueue(token: string, draftId: string) {
  return sleeperGraphql(token, {
    operationName: "draft_queue",
    variables: { draft_id: draftId },
    query: DRAFT_QUEUE_QUERY,
  });
}

5. Normalize queue players.

Create:

src/lib/sleeper/normalizers/draftQueue.ts

Add:

export function normalizeDraftQueue(
  queue: string[],
  playersById: Record<string, any>
): DraftQueuePlayer[] {
  return queue.map((playerId, index) => {
    const player = playersById[playerId];

    return {
      playerId,
      rank: index + 1,
      name: player?.full_name || player?.first_name + " " + player?.last_name || playerId,
      position: player?.position,
      team: player?.team,
    };
  });
}

For now:

- Refetch every 10 seconds while the draft is active.

Important:

10. Do not implement queue write actions yet.

For this step, only read and display the queue.

Do not add:
- add to queue
- remove from queue
- reorder queue
- draft from queue

Those require separate writable mutations that still need to be captured from Sleeper DevTools.

11. Add basic debugging without exposing secrets.

Allowed console logs:
- draftId
- queue length
- loading/error status

Never log:
- Sleeper token
- cookies
- authorization headers

12. Acceptance criteria.

This feature is complete when:
- The live draft room loads the user’s current Sleeper draft queue.
- Empty queue shows a clean empty state.
- Queue updates after manual refresh.
- Queue auto-refreshes every 10 seconds while the draft room is open.
- Token is never printed or exposed.
- The app does not crash if the queue operation fails.
