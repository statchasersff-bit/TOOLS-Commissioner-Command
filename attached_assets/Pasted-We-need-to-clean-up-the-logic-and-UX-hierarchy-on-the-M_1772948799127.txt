We need to clean up the logic and UX hierarchy on the My Team page so the labels are consistent and the page reads more clearly.

CURRENT ISSUE
The page can currently show conflicting labels like:
- Archetype: Balanced
- Suggested Strategy: Dynasty Powerhouse
- Economy Label / Quadrant: Dynasty Death Star

These should not conflict.

Example profile:
- RED rank = 5 / 12
- DYN rank = 1 / 12
- PCKS rank = 6 / 12

This should not feel like “Balanced” if the long-term profile is elite.

GOAL
Make the My Team page use one consistent team identity system, improve card order / hierarchy, and make labels easier to understand.

====================================
1) UNIFY TEAM IDENTITY LABELING
====================================

Right now we have multiple naming systems:
- Archetype
- Economy label / quadrant label
- Suggested Strategy

We need to separate these clearly so they do different jobs.

Please refactor to use these definitions:

A) ARCHETYPE
This should be the primary classification label from the tier logic.
Examples:
- Juggernaut
- Win-Now
- Future Powerhouse
- Pick Hoarder
- Contender
- Rebuilder
- Balanced
- Taco

This is the main “what kind of team is this?” label.

B) DYNASTY WINDOW / QUADRANT
This should be a separate visual placement label based on the current-vs-future chart.
Examples:
- Dynasty Death Star
- Win-Now Kings
- Rebuild With Ammo
- Rebuild Hell

This is NOT the same thing as Archetype.
It should be displayed as a secondary contextual label, not the primary identity.

C) SUGGESTED DIRECTION
This should be actionable advice, not a label that competes with Archetype.
Examples:
- Aggressively buy RB depth
- Consolidate depth for elite starters
- Sell aging veterans for picks
- Stay patient and build through youth

Remove any strategy labels like “Dynasty Powerhouse” from the Suggested Strategy field if they duplicate or conflict with Archetype.

If we still want a short non-action label there, rename that section to:
- Competitive Window
or
- Team Outlook

But the preferred setup is:
- Archetype = classification
- Dynasty Window = chart quadrant
- Suggested Direction = actionable advice
