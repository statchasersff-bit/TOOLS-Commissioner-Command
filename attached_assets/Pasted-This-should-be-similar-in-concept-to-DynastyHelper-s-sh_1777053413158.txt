This should be similar in concept to DynastyHelper’s share team view, but with StatChasers branding and better UX.

Tab placement:
- Add “Share My Team” as a new main tab in Dynasty Command.
- It should sit near My Team / Portfolio / League Analyzer if applicable.

Main Layout:
Create a two-column layout on desktop:
- Left column: team summary/share card controls
- Right column: roster preview
On mobile:
- Stack vertically.

Top Controls:
Add:
- League/team selector dropdown
- Copy Link button
- Export Image button
- Export Anonymous button
- Optional: Copy Blurb button

Buttons:
1. Copy Link
- Copies a shareable URL with league/team context.
- Include query params for leagueId and rosterId/teamId.
- Show toast: “Share link copied.”

2. Export Image
- Exports the visible team card/share layout as a PNG.
- Use html-to-image or the existing image export library if already available.
- Include StatChasers branding.
- Show toast on success or error.

3. Export Anonymous
- Same export, but hides:
  - Manager name
  - League name if privacy toggle is on
  - Any user/avatar that identifies the owner
- Replace with:
  - “Anonymous Dynasty Team”
  - “12-Team SF Dynasty”
- Still show roster, scores, positional values, and league settings.

4. Copy Blurb
Generate a text blurb useful for Discord, Sleeper chat, Reddit, or orphan recruiting.

Example:
“12T Dynasty SF PPR TEP team in [League Name]. Record: 7-2. Core players: Ja’Marr Chase, Malik Nabers, Josh Jacobs, Baker Mayfield. Team strengths: WR, Picks. Needs: QB. View full team: [share link]”

Positional Value Card:
Show QB, RB, WR, TE, Picks rows.
Each row should include:
- Small horizontal bar
- Rank, ex: #2 of 12
- Label:
  - Elite
  - Strong
  - Average
  - Weak
Use color-coded labels.

Suggested positional score logic:
- Use existing positional value/strength if already available.
- If not, estimate from player market values grouped by position.
- Rank each team within the league by position group value.
- Label:
  - Rank 1-3 = Elite/Strong depending on league size
  - Middle = Average
  - Bottom third = Weak

Backend / Data Requirements:
Create a normalized share team object:

{
  leagueId,
  leagueName,
  rosterId,
  managerName,
  teamName,
  avatar,
  record: {
    wins,
    losses,
    ties,
    winPct
  },
  standingRank,
  teamCount,
  settings: {
    isDynasty,
    isSuperflex,
    isBestBall,
    ppr,
    tep,
    passingTd,
    rosterPositions
  },
  scores: {
    overall,
    contender,
    rosterValue,
    projectedPoints,
    futurePicks
  },
  ranks: {
    overallRank,
    rosterValueRank,
    projectedPointsRank,
    futurePicksRank,
    qbRank,
    rbRank,
    wrRank,
    teRank,
    picksRank
  },
  strengths: {
    qb,
    rb,
    wr,
    te,
    picks
  },
  roster: {
    QB: [],
    RB: [],
    WR: [],
    TE: [],
    Picks: [],
    IR: [],
    Taxi: []
  },
  corePlayers: [],
  weaknesses: [],
  archetype
}

Core player logic:
- Top 4-6 players by market value.
- Prefer QB/WR/RB/TE starters.
- Exclude low-value depth pieces.

Weakness logic:
- Any position group ranked bottom third in the league.
- Especially flag QB weakness in SF leagues.

Archetype logic:
- Elite Contender = top 2 overall score or top 2 projected points + strong roster value.
- Contender = top 4 overall/projected points.
- Fringe = middle third.
- Rebuild = bottom third but high picks value.
- Orphan Target = weak current roster but strong picks/youth.
