Add authenticated Sleeper GraphQL support for future rookie/draft pick ownership using the roster_draft_picks operation.

Goal:
Dynasty Command needs to fetch and display future draft pick assets for each league. This will power roster asset views, trade calculator pick inventory, team outlook, and future trade features.

Operation discovered from Sleeper:
POST https://sleeper.com/graphql

operationName: roster_draft_picks

Query:
query roster_draft_picks($league_id: ID!) {
  roster_draft_picks(league_id: $league_id) {
    roster_id
    season
    round
    owner_id
  }
}

Important interpretation:
- roster_id = the team/roster that currently owns the pick
- owner_id = the original team/roster the pick came from
- season = draft year
- round = pick round

Example:
{
  owner_id: 10,
  roster_id: 1,
  round: 2,
  season: "2026"
}

This means:
Roster 1 currently owns Roster 10’s 2026 2nd-round pick.

Implementation requirements:

1. Add a centralized Sleeper GraphQL client if one does not already exist.

Create or update:
src/lib/sleeper/graphql/client.ts

It should expose a function like:

export async function sleeperGraphql(token, payload) {
  const res = await fetch("https://sleeper.com/graphql", {
    method: "POST",
    headers: {
      "content-type": "application/json",
      "authorization": token,
      "x-sleeper-graphql-op": payload.operationName,
    },
    body: JSON.stringify(payload),
  });

  if (!res.ok) {
    throw new Error(`Sleeper GraphQL error: ${res.status}`);
  }

  const json = await res.json();

  if (json.errors) {
    throw new Error(json.errors.map(e => e.message).join(", "));
  }

  return json.data;
}

Important:
Sleeper’s browser request uses:
authorization: <JWT>
not:
authorization: Bearer <JWT>

So pass the raw token exactly.

2. Add the roster draft picks query.

Create or update:
src/lib/sleeper/graphql/queries/rosterDraftPicks.ts

Add:

export const ROSTER_DRAFT_PICKS_QUERY = `
  query roster_draft_picks($league_id: ID!) {
    roster_draft_picks(league_id: $league_id) {
      roster_id
      season
      round
      owner_id
    }
  }
`;

export async function getRosterDraftPicks(token: string, leagueId: string) {
  return sleeperGraphql(token, {
    operationName: "roster_draft_picks",
    variables: { league_id: leagueId },
    query: ROSTER_DRAFT_PICKS_QUERY,
  });
}

4. Normalize the pick data.

Create:
src/lib/sleeper/normalizers/draftPicks.ts

Add a function that converts Sleeper’s response into clean app data.

Example:

export function normalizeRosterDraftPicks(
  leagueId: string,
  picks: SleeperRosterDraftPick[]
): NormalizedDraftPick[] {
  return picks.map((pick) => ({
    leagueId,
    currentRosterId: pick.roster_id,
    originalRosterId: pick.owner_id,
    season: pick.season,
    round: pick.round,
    label: `${pick.season} Round ${pick.round} Pick from Roster ${pick.owner_id}`,
  }));
}
