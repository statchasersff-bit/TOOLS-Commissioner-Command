Rebuild mode is actually even more powerful strategically because you can create a very “smart GM” experience instead of just:

“Sell old players for picks.”

The core philosophy becomes:

“Convert fragile short-term production into stable long-term dynasty insulation while preserving future upside.”

Win-now mode optimizes:

lineup points
starter upgrades
contention windows

Rebuild mode optimizes:

insulation
age curve
liquidity
future appreciation
market timing

This is where StatChasers can become incredibly differentiated.

Core Philosophy of Rebuild Mode

The engine should answer:

“How can this team maximize long-term dynasty value growth while minimizing future value decline risk?”

NOT:

maximize current points
maximize projections
maximize lineup strength

Instead:

increase dynasty appreciation potential
reduce aging asset exposure
improve future flexibility
accumulate liquid value
increase championship window duration
