Core Philosophy of Win-Now Mode

The engine should answer:

“How can this team improve weekly starting lineup output while sacrificing the least amount of long-term dynasty value?”

NOT:

maximize dynasty value
maximize total roster value
maximize bench points

ONLY:

maximize starter production delta
minimize dynasty overpay
exploit roster imbalances
Step 1 — Determine Team Needs

You already have positional profile rankings.

Example:

Position	Dynasty Rank	Win-Now Rank
QB	8th	7th
RB	1st	1st
WR	11th	10th
TE	12th	11th

This team is:

elite at RB
weak at WR
catastrophic at TE
below average at QB

So the engine should produce:

Primary Need: TE
Secondary Need: WR
Tertiary Need: QB
Avoid buying: RB
Step 2 — Measure Positional Urgency

Not all weak positions matter equally.

You need:

Positional Upgrade Urgency Score

Example:

urgency =
(
 leagueAverageStarterValue
 -
 yourStarterValue
)
*

Example:

Position	Gap vs Avg	Scarcity	Urgency

So:

TE > WR >>> QB

This prevents the engine from wasting time suggesting tiny QB upgrades.

Step 3 — Identify Expendable Dynasty Value

This is the MOST IMPORTANT PART.

The engine needs to identify:

Which dynasty assets can be removed with minimal impact to weekly starter output?

This is where your platform becomes elite.
